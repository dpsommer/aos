# Stormcast Eternals FAQ

Official rulings that concern Stormcast Eternals, from the [Rules Updates, October 2026](https://assets.warhammer-community.com/eng_28-10_aos_core_rules_and_key_downloads_rules_updates-aghvsvstmk-u8wyh173fe.pdf). They're paraphrased; the PDF (page numbers below) has the exact wording.

## Battletome (p. 74)

**Q:** Can 'Ruination Chamber' react to an enemy ability that targets the unit outside the regular turn sequence, e.g. a Deployment Phase ability?

**A:** Yes.

**Q:** If 'Ruination Chamber' succeeds against an ability that targets several units or has several effects (e.g. 'Power Through'), does the opponent still resolve it for the other units?

**A:** Yes. It only stops the effect on the unit that used 'Ruination Chamber'.

## Other rulings

**Q:** Can a unit use a Move ability and then, in the same movement phase, be removed and set up again, e.g. a non-Monster Stormcast Eternals unit moving wholly within 6" of a Stormreach Portal and then using 'Step Into the Storm'? (Core Rules 24.0, p. 7)

**A:** Yes. Units can't use Move abilities in the movement phase after being set up that turn, but they can before.

**Q:** Does the Vanguard-Raptors with Longstrike Crossbows' 'Headshot' let them ignore 'Protect at all Costs' in the Twisted by Rage battleplan? (Path to Glory: Ravaged Coast, p. 78)

**A:** No.
