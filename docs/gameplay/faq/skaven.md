# Skaven FAQ

Official rulings that concern Skaven, from the [Rules Updates, October 2026](https://assets.warhammer-community.com/eng_28-10_aos_core_rules_and_key_downloads_rules_updates-aghvsvstmk-u8wyh173fe.pdf). They're paraphrased; the PDF (page numbers below) has the exact wording.

## Battletome (p. 67)

**Q:** If a Stormfiends unit picked as the target of the 'Filth-crust' prayer with a chanting roll of 8+ gains Crit (Mortal), how does that interact with 'Shock Gauntlets'?

**A:** Crit (Mortal) inflicts mortal damage equal to the Damage characteristic and ends the attack sequence, so 'Shock Gauntlets' has no further effect.

**Q:** If an enemy unit under 'Gaze of the Gnaw' must attack Vizzik Skour, can its models that aren't within his combat range after piling in attack?

**A:** No.

**Q:** If a Warp-Grinder uses 'Tunnel Skulkers' to set up another Warp-Grinder in the tunnels below, can both use 'Warp-Ambush'?

**A:** Yes.

**Q:** When using the Grey Seer's 'Warpstone Shards', is the spell miscast if the 3D6 casting roll has two or more 1s before a dice is removed?

**A:** Yes.

**Q:** Does a unit with Fly that passes across a Gnawhole ignore 'Volatile Ground'?

**A:** No. It still passed across the Gnawhole, so the effect applies.

**Q:** Can a Mutated Menagerie Hell Pit Abomination picked as the target of 'Rampaging Demise' avoid being destroyed by rolling a 5 or 6 for 'Too Horrible To Die'?

**A:** Yes.

## Other rulings

**Q:** After 'Gnaw Through Reality' is cast on a Scourge of Aqshy Grey Seer on Screaming Bell, can it use 'Tunnels Through Reality' to be set up wholly within 6" of another friendly Gnawhole? (Other Digital Downloads, Scourge of Aqshy, p. 34)

**A:** No. 'Gnaw Through Reality' only lets it be treated as a Gnawhole when abilities from the Gnawhole warscroll are used; it doesn't let it use those abilities.

**Q:** When an ability targets 'non-Skryre Moulder' units (e.g. the Brood Terror's 'Lend a Claw'), must the target lack both keywords? (Core Rules 5.1, p. 4)

**A:** No. 'non-' applies only to the keyword it's attached to, so the target can't have Skryre but must have Moulder. Excluding both would be written 'non-Skryre non-Moulder'.

**Q:** If an ability ignores 'Guarded Hero' when picking targets (e.g. the Warlock Engineer's 'Sniper-master'), does the attacking unit still take the -1 to hit? (Core Rules 25.0, p. 7)

**A:** Yes.

**Q:** In Path to Glory, can 'Splinters of the Vermindoom' set up a Gnawhole that isn't on the roster? (Path to Glory: Ravaged Coast, p. 78)

**A:** Yes. A battle trait or warscroll ability can set up faction terrain that isn't on the roster.
