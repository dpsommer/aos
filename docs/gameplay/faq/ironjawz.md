# Ironjawz FAQ

Official rulings that concern Ironjawz, from the [Rules Updates, September 2026](https://assets.warhammer-community.com/eng_23-09_aos_core&key_rule_updates-eu6fu82jl3-dlyuiignte.pdf). Ironjawz share the Orruk Warclans battletome section with Kruleboyz. They're paraphrased; the PDF (page numbers below) has the exact wording.

## Battletome (Orruk Warclans, p. 63)

**Q:** When using the Big Waaagh! Army of Renown's 'Notorious Bosses' ability, can I give a target a heroic trait that another unit already has?

**A:** No.

**Q:** Can each part of the Foot of Gork use 'Wandering Destruction' each turn?

**A:** No. It's a single manifestation with multiple parts, so it can only use that ability once each turn.

**Q:** In the Ironjawz Bigmob Spearhead, are the Brute Ragerz set up during the deployment phase?

**A:** Yes. Only the Brutes are not set up during deployment; the Brute Ragerz are a different unit and are set up normally.

**Q:** Is damage inflicted on a unit that finished a move within 6" of a terrain feature trampled by Gork (Zoggrok's Ironmongerz) damage inflicted by a Prayer ability?

**A:** Yes.

## Other rulings

**Q:** If ability A references ability B from another ruleset, can I use B? For example, can Gordrakk in a Big Waaagh! army use 'Voice of Gork' or the 'Ironjawz Waaagh!' it references? (Advanced Rules, Army Composition 2.2, p. 12)

**A:** No. 'Voice of Gork' reacts to a Waaagh! ability, and the Big Waaagh! faction rules have none, so it can't be used in a Big Waaagh! army and doesn't grant access to Waaagh! abilities.
