# Lumineth Realm-lords FAQ

Official rulings that concern Lumineth Realm-lords, from the [Rules Updates, October 2026](https://assets.warhammer-community.com/eng_28-10_aos_core_rules_and_key_downloads_rules_updates-aghvsvstmk-u8wyh173fe.pdf). They're paraphrased; the PDF (page numbers below) has the exact wording.

## Battletome (p. 56)

**Q:** With Varinor, Rune of Strength depicted twice on the battle scripture and 4 targets picked, does each target get +4 to run and charge rolls?

**A:** No. Each target gets +1 to run rolls and +1 to charge rolls.

**Q:** Can I make an unbinding roll before deciding whether to use 'Release Arcane Charge'?

**A:** Only if the unbinding roll is in the declare step of the ability being reacted to. If it's in the effect step, as in 'Unbind', declare 'Release Arcane Charge' before making the roll.

**Q:** Using the Warhost of Duality battle formation: 1) If Lyrior Uthralle has Strike-first (e.g. from 'Focused Fury'), can 'Strike as One' let another unit fight immediately after her? 2) If no other units have Strike-first and it's my turn to pick the first unit to fight, can I then pick 2 other eligible friendly units to fight?

**A:** 1) Yes, as long as no other units have Strike-first, or the second unit also has Strike-first. 2) Yes.

## Other rulings

Most of these concern the Shrine Luminor, which lets a unit be placed on it. Range and visibility are then measured to and from the terrain feature instead of the unit (Advanced Rules, Terrain 1.5).

**Q:** If a non-Fly Infantry Hero (e.g. a Scinari Cathallar) is a Shrine Luminor's Shrine Guardian and is within 1" of an Obscuring terrain feature, is it visible to enemy abilities that target it? (Core Rules 6.0, p. 5)

**A:** Yes.

**Q:** Must 'Covering Fire' target a faction terrain feature that is the closest target? (Advanced Rules, Commands 4.0, p. 10)

**A:** No, and it can't. But if the terrain feature has a unit on it, like a Shrine Luminor, it must be targeted when it's closest.

**Q:** If an ability sets a unit up more than 9" from all enemy units, can it be set up within 9" of a faction terrain feature? (Advanced Rules, Terrain 1.5, p. 10)

**A:** Yes, unless the terrain feature has a unit on it, like a Shrine Luminor.

**Q:** Can a unit on a faction terrain feature be picked as the target of an enemy ability, e.g. the hero on a Shrine Luminor picked by the Realmshaper Engine's 'Power Unleashed'? (Advanced Rules, Terrain 1.5, p. 10)

**A:** Yes.

**Q:** Must a unit use a Retreat ability to move away from a faction terrain feature with a Move characteristic of 0"? (Advanced Rules, Terrain 1.5, p. 10)

**A:** No, any Move ability will do, unless the terrain feature has a unit on it, like a Shrine Luminor. Then a Retreat ability is needed.
