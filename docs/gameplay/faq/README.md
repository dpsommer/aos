# Faction FAQs

Each faction's official FAQ rulings from the [Rules Updates, September 2026](https://assets.warhammer-community.com/eng_23-09_aos_core&key_rule_updates-eu6fu82jl3-dlyuiignte.pdf), one document per faction. Each document has the faction's own FAQs, then rulings from other sections (core rules, Advanced Rules, General's Handbooks, Other Digital Downloads, Spearhead and Path to Glory) that name its units or abilities. The rulings are paraphrased; the PDF is the source of truth.

The errata in the same PDF change rules text, so they belong in the faction data (`data/factions/`), not here. See [Faction data](../../technical/faction-data.md).
