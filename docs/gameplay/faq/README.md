# Faction FAQs

Each faction's official FAQ rulings from the [Rules Updates, October 2026](https://assets.warhammer-community.com/eng_28-10_aos_core_rules_and_key_downloads_rules_updates-aghvsvstmk-u8wyh173fe.pdf), one document per faction. Each document has the faction's own FAQs, then rulings from other sections (core rules, Advanced Rules, General's Handbooks, Other Digital Downloads, Spearhead and Path to Glory) that name its units or abilities. The rulings are paraphrased; the PDF is the source of truth.

The errata in the same PDF change rules text, so they belong in the faction data (`data/factions/`), not here. See [Faction data](../../technical/faction-data.md).
