# Sylvaneth FAQ

Official rulings that concern Sylvaneth, from the [Rules Updates, October 2026](https://assets.warhammer-community.com/eng_28-10_aos_core_rules_and_key_downloads_rules_updates-aghvsvstmk-u8wyh173fe.pdf). They're paraphrased; the PDF (page numbers below) has the exact wording.

## Battletome (p. 76)

**Q:** Which units can Alarielle's 'The Goddess of Life' replace?

**A:** Only Alarielle.

**Q:** How many models are in a Kurnoth Hunters unit replaced by 'Awaken Slumbering Spirits'?

**A:** One.

**Q:** Can 'Fury of the Forest' pick a friendly unit that is in combat with both an enemy unit and an enemy manifestation or faction terrain feature?

**A:** Yes.

**Q:** Does the Soulpod Grove in the Soulpod Guardians Army of Renown count as an Awakened Wyldwood?

**A:** Yes. It uses the Awakened Wyldwood warscroll and counts as a single Awakened Wyldwood for abilities.

**Q:** Is a unit wholly within the creeping overgrowth if it isn't wholly within range of any single terrain feature with an overgrown token, but is wholly within the overlapping ranges of several?

**A:** Yes.

## Other rulings

**Q:** If an ability refers to the closest object and several are tied (e.g. two terrain features equally close to an Awakened Wyldwood using 'Ever Growing'), which is affected? (Core Rules 5.2, p. 4)

**A:** The player who used the ability chooses.

**Q:** If 'Seed of Rebirth' would stop a unit being destroyed by negating the remaining damage and healing it, but another ability (e.g. 'Quenching the Flames') prevents it healing, is the unit destroyed? (Core Rules 21.0, p. 6)

**A:** Yes.

**Q:** Are relics terrain features for abilities such as 'Strike and Fade'? (Spearhead: City of Ash, p. 19)

**A:** No.

**Q:** In Path to Glory, can 'Treesong' set up an Awakened Wyldwood that isn't on the roster? (Path to Glory: Ravaged Coast, p. 78)

**A:** Yes. A battle trait or warscroll ability can set up faction terrain that isn't on the roster.
