# Kruleboyz FAQ

Official rulings that concern Kruleboyz, from the [Rules Updates, October 2026](https://assets.warhammer-community.com/eng_28-10_aos_core_rules_and_key_downloads_rules_updates-aghvsvstmk-u8wyh173fe.pdf). Kruleboyz share the Orruk Warclans battletome section with Ironjawz. They're paraphrased; the PDF (page numbers below) has the exact wording.

## Battletome (Orruk Warclans, p. 64)

**Q:** When using the Big Waaagh! Army of Renown's 'Notorious Bosses' ability, can I give a target a heroic trait that another unit already has?

**A:** No.

**Q:** Can each part of the Foot of Gork use 'Wandering Destruction' each turn?

**A:** No. It's a single manifestation with multiple parts, so it can only use that ability once each turn.
